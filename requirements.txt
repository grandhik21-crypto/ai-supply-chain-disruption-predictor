# Core runtime dependencies for the Streamlit dashboard.
#
# Install with:  python3 -m pip install -r requirements.txt
#
# This file deliberately EXCLUDES PyTorch and Transformers, which are only
# needed to (re)generate news sentiment with FinBERT. Keeping them out lets the
